4.12 Sử dụng Comparable interface
- What class should implement the Comparable interface?
Class Media nên implement Comparable<Media> vì tất cả các đối tượng trong Cart đều là Media, việc implement ở lớp cha sẽ giúp tất cả các lớp con (Book, CD, DVD) kế thừa và so sánh lẫn nhau.
- In those classes, how should you implement the compareTo() method to reflect the ordering that we want?
Ghi đè (override) phương thức compareTo(Media other) trong class Media. So sánh this.getTitle() và other.getTitle(). Khác nhau thì trả về kết quả đó giống nhau thì trả về Float.compare(other.getCost(), this.getCost()) để sort cost .

- Can we have two ordering rules of the item (by title then cost and by cost then title) if we use this Comparable interface approach?
Không. Comparable chỉ cho phép định nghĩa DUY NHẤT MỘT luật sắp xếp mặc định.

- Suppose the DVDs has a different ordering rule from the other media types, that is by title, then decreasing length, then cost. How would you modify your code to allow this?
Override method compareTo(Media other) bên trong class DigitalVideoDisc. 
Trong hàm này, dùng  instanceof kiểm tra `if (other instanceof DigitalVideoDisc)`. 
Nếu đúng là DVD thì ép kiểu về DigitalVideoDisc và lần lượt so sánh Title tới Length giảm dần -> Cost.
Nếu không phải là DVD thì dùng return super.compareTo(other);
